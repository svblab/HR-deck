# DECISIONS — журнал решений Maintainer

Здесь записываются технические и процессные решения Maintainer с датами. Новые записи добавляются в конец; запись не переписывается, а уточняется новой записью. Решения по ТЗ находятся в самом `docs/TZ-v2.md` (журнал, раздел 0.9). Репозиторий публичный: коммерческие сведения и персональные данные сюда не пишутся.

| Дата | Решение |
|---|---|
| 2026-10-24 | ТЗ v2 принято (версия 2.0), PR #153. Слияние #153 считается выпуском: любая следующая правка ТЗ — версия 2.1 с записью в журнале 0.9 (раздел 0.2.3). |
| 2026-10-24 | Этап P5 (эпики E0–E17) ведётся по карточкам `docs/work/`: одна карточка — одна ветка — один PR. |
| 2026-10-25 | Размер карточки (вариант Б): `код=300 тесты=600` изменённых строк; документы, карточка и отчёт не считаются; планировщик может задать другой бюджет; превышение — остановка и diff-first. §5 протокола (файл длиннее 300 строк) остаётся отдельным правилом. |
| 2026-10-25 | Роли распределены между моделями: планировщик и исполнитель — Cursor Cloud Agent (по возможности разные модели), проверяющие и рецензенты — веб-модели (GPT, Grok, Claude). Автор плана не рецензирует его, исполнитель не проверяет свою карточку, проверяющий не та же модель, что исполнитель. Claude не является ведущим планировщиком. |
| 2026-10-25 | Код и документы пишутся только в Cursor Cloud Agent (Linux). Локальный Cursor — оператор GitHub (`gh`): issue, закрытия, проверка `gh pr create`. |
| 2026-10-25 | Гигиена репозитория: удалены 47 слитых и заменённых веток (где были уникальные коммиты — сохранены архивными тегами `archive/*`); устаревшие документы перенесены в `docs/archive/`; заведены issue #161 и #162. |
| 2026-10-25 | Тексты файлов передаются агентам через чат с маркером `<<BL>>` вместо пустых строк и проверкой SHA-256 (см. `CONTEXT.md`). |
| 2026-10-25 | Первой работой планировщика на Cursor становится адденд ADR-0011 (блокер E1); рецензирует веб-модель. |
