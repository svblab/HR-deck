# DECISIONS — журнал решений Maintainer

Здесь записываются технические и процессные решения Maintainer с датами. Новые записи добавляются в конец; запись не переписывается, а уточняется новой записью. Решения по ТЗ находятся в самом `docs/TZ-v2.md` (журнал, раздел 0.9). Репозиторий публичный: коммерческие сведения и персональные данные сюда не пишутся.

|---|---|

| 2026-10-27 | Адденд ADR-0010 (идентичность «владелец плюс код», обмен справочников значений) принят слиянием PR #167; блокер нормы для E1-08, E1-09, E1-10 снят. Решения Maintainer 1–5 записаны в самом аддендуме: (1) пробелы внутри названия филиала схлопываются в один, «А Б» ≠ «АБ», отдельная функция нормализации, правило ФИО не меняется; (2) часть 4 п. 3–4 ADR-0010 остаётся для организационных справочников; (3) локальные `id` в пакете не передаются (ТЗ 7.14.5), удаление идёт вместе с числом протокола в E5; (4) владелец строки справочника значений — домашний филиал отправителя из метаданных (ТЗ 7.4.2), кодирование поля — N4/E5; (5) ссылка карточки допустима на базовый набор или на запись домашнего филиала отправителя. |
