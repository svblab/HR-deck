## 6. Ловушки

- Пустые строки в чате теряются: тексты файлов передаются с `<<BL>>` и проверкой SHA-256 (`CONTEXT.md`).
- Веб-модели путают номера строк: читать файлы по ссылкам с хэшем коммита и требовать дословные цитаты.
- Cloud Agent не создаёт PR (его `gh` не авторизован, HTTP 401) и не сливает: PR открывает локальный Cursor через `gh` по команде Maintainer, сливает Maintainer; push только по явной команде и явным refspec.
- `work_status.py` сканирует `docs/work/*/*.md` кроме `_templates` и `reports`: файлы без front matter туда не класть.
- Слитые ветки удаляются только по команде Maintainer.
- Каждый промт Cloud Agent начинается с проверки среды (`uname -a` показывает Linux, `pwd` — `/workspace`), иначе стоп: правка F-01 в PR #174 по ошибке выполнена локальным Cursor на Windows (DECISIONS, 2026-11-02).
- Условие остановки в промте («если ворота не прошли, не пушить») исполнитель соблюдает буквально; нарушение — находка по §0 (PR #174, коммит 80e92cc).
- После смены модели Cloud Agent возобновляет прежнюю задачу служебным сообщением «Continue»; при остановке по ошибке в FIND это привело к коммиту без команды Maintainer (docs-PR закрытия E0, 2026-11-02). После смены модели начинайте новую задачу; остановку снимает только новая команда Maintainer.
