## 4. Находки инвентаризации E0 (факты на 2026-10-25)

- `employment_type_id` передаётся в пакете целым числом (`src/services/directory_sync.py:155-161`), комментарий там называет это намеренным исключением и устарел; issue #155; норма принята аддендумом ADR-0010 (PR #167), реализуют карточки E1; удаление целых `id` из организационных строк — E5.
- CSV: импорт только `utf-8-sig` с запятой (`src/services/employee_files.py:37`); экспорт только XLSX.
- Пароль: проверяется только непустота (`src/services/account_management.py:97, 196`, `src/domain/password_kdf.py:40-44`); политики нет (эпик E11).
- Базовые статусы: сервис разрешает переименование и скрытие без защиты (`src/services/availability_statuses.py:79-133`); входа в UI нет.
- CONFLICT при импорте: сравниваются `external_id` и ФИО, филиал не сравнивается (`src/services/employee_reconciliation.py:54-60`); правило закрывает ADR-0011-адденд.
- Пакетное применение (#124) реализовано, но не соответствует 10.7: нет условия домашнего филиала, мастер после сводки не открывается сам.
- Миграции только SQL, каждая в `BEGIN` и `ROLLBACK` (`src/data/migrations.py:259-289`); условный отказ делается временным триггером с `RAISE`; проверено на SQLite (ADR-0011-адденд, §1.1).

## 6. Ловушки

- Пустые строки в чате теряются: тексты файлов передаются с `<<BL>>` и проверкой SHA-256 (`CONTEXT.md`).
- Веб-модели путают номера строк: читать файлы по ссылкам с хэшем коммита и требовать дословные цитаты.
- Cloud Agent не создаёт PR (его `gh` не авторизован, HTTP 401) и не сливает: PR открывает локальный Cursor через `gh` по команде Maintainer, сливает Maintainer; push только по явной команде и явным refspec.
- `work_status.py` сканирует `docs/work/*/*.md` кроме `_templates` и `reports`: файлы без front matter туда не класть.
- Слитые ветки удаляются только по команде Maintainer.
