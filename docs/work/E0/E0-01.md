## Цель
Скрипт без внешних зависимостей читает front matter карточек `docs/work/<EPIC>/*.md`, печатает таблицу состояния и список карточек, которые можно брать, и проверяет согласованность.

## Не входит
Интеграция с CI, scope-guard, правка карточек, запись любых файлов.

## Входные условия
1. `git status --short` пуст, ветка создана от `origin/master`.
2. Существуют `docs/work/README.md`, `docs/work/_templates/CARD.md`, `docs/work/E0/E0-01.md`.

## Поведение
- Читает `docs/work/*/*.md`; пропускает `README.md`, каталоги `_templates` и `reports`.
- Front matter лежит между первой и второй строкой `---`. Строка `ключ: значение`; комментарий после ` #` отбрасывается; значение `[a, b]` — список строк; пустое значение — пустая строка.
- Вывод по умолчанию: таблица ID, EPIC, status, ждёт (ID незавершённых `depends_on`), можно брать (да/нет).
- `--ready` печатает только ID карточек со status `ready`, у которых все `depends_on` в статусе `done`.
- Проверки (сообщения в stderr, код выхода 1): нет обязательного ключа (id, epic, title, status, depends_on, requires_adr, spec, branch, size_budget, allowed_paths, forbidden_paths, report); status не из draft, ready, blocked, done; id не совпадает с именем файла; `depends_on` ссылается на несуществующий ID; status `done` без заполненного report; дубликат id.
- Нет карточек: сообщение «карточек нет», код 0.
- Python 3.11+, только стандартная библиотека; корень репозитория определяется от расположения скрипта.

## Критерии приёмки
1. `python3 scripts/work_status.py` печатает таблицу, где E0-01 имеет status ready, код выхода 0.
2. `python3 scripts/work_status.py --ready` печатает E0-01.
3. `pytest tests/unit/test_work_status.py -q` проходит; тесты работают во временном каталоге и покрывают: разбор списка, комментарий, зависимость, `done` без report, неизвестный статус, дубликат id, пустой каталог.
4. `ruff check scripts/work_status.py tests/unit/test_work_status.py` без замечаний.
5. `git diff --stat origin/master...HEAD`: только `allowed_paths`, эта карточка и файл отчёта; не более 300 строк без карточки и отчёта.

## Что оставить после себя
Скрипт, тесты, отчёт `docs/work/E0/reports/E0-01.<agent>.md` с разделом «Для следующего»; в этой карточке `status: done` и заполненное `report`.
