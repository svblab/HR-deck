## Цель
Закрыть пробелы, найденные при пилоте E0-01: карточка с пустым `id` не должна проходить проверку; `epic` в карточке должен совпадать с именем каталога; недостающие тесты; ruff в CI проверяет и `scripts/`.

## Не входит
Любые изменения формата карточек и вывода таблицы, scope-guard, другие проверки CI.

## Входные условия
1. `python3 scripts/work_status.py` на `origin/master` завершается кодом 0.
2. В `.github/workflows/ci.yml` шаг ruff содержит `ruff check src tests` (проверьте точную строку).

## Критерии приёмки
1. Карточка с `id:` без значения: `python3 scripts/work_status.py` печатает ошибку об идентификаторе в stderr и завершается кодом 1 (тест во временном каталоге).
2. Карточка `docs/work/E2/E1-01.md` с `epic: E1`: ошибка о несовпадении `epic` с каталогом, код 1 (тест).
3. Тесты на отсутствующий обязательный ключ и на несовпадение `id` с именем файла проходят: `pytest tests/unit/test_work_status.py -q`.
4. `ruff check src tests scripts` без замечаний локально; в `.github/workflows/ci.yml` шаг ruff проверяет `scripts`. Если ruff находит замечания в других скриптах `scripts/`, остановитесь: исправление чужих скриптов вне карточки, опишите в отчёте.
5. `python3 scripts/work_status.py` на реальном дереве по-прежнему код 0.
6. `git diff --stat origin/master...HEAD`: только `allowed_paths`, эта карточка и отчёт.
