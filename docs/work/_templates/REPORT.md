## Среда
По одной строке: `pwd`, ОС, `git rev-parse --show-toplevel`, `git status --short`, `git rev-parse HEAD`.

## Scope statement (§0.5)
Карточка, объём, перечень изменённых файлов. Подтверждение, что вне объёма ничего не менялось. Если было смещение — сказать прямо.

## Размер
Изменённые строки: код N, тесты M против `size_budget` карточки. Документы, карточка и отчёт не считаются.

## Что сделано
По файлам: что и зачем. Для правок существующих файлов — unified diff целиком; «Было/Стало» полным текстом только для файлов короче 30 строк.

## Команды и вывод
Каждая команда и её полный вывод. Куски до ~25 КБ; при обрыве `CONTINUED`.

## Критерии приёмки
№ -> pass / fail / не проверено, с доказательством (команда, вывод). Критерии, зависящие от статуса карточки, снимайте до смены статуса.

## Находки (§0.2)
Симптом, предполагаемая причина, предполагаемый объём. Не исправлять.
