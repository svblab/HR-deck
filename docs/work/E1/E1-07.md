## Цель
Действие «В архив» показывает только три архивирующих вида; для `transferred` — выбор филиала назначения (не скрытый, не домашний); комбо вида на форме действующей карточки без архивирующих кодов; UI вызывает **новые** методы E1-06 (не удаляет старые в сервисе). В форме «Архив» — элемент управления фильтром ошибочных записей: при включении `_reload` передаёт в `RosterService.list_rows` `RosterFilters` с флагом из E1-18 (`only_erroneous` или согласованное имя из domain); при выключении — только `name_query`, как сейчас (`src/ui/archive_dialog.py:112-116`). После `list_rows` по-прежнему отбор `row.is_archived`.

## Не входит
Логика `RosterRow` / `apply_filters` / `_to_row` (E1-18); логика сервиса архива (E1-06); удаление deprecated методов (E1-12); домашний филиал в архиве (E4); обмен и пакет (E1-09); главный экран (`roster_panel.py` — только действующие карточки, ТЗ 4.5.4).
