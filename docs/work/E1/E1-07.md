## Цель
Действие «В архив» (`src/ui/employee_card_form.py:385-388`) — три архивирующих вида; для `transferred` — филиал назначения; UI вызывает `archive_employee_with_archiving_code` и `restore_employee_with_employment_type` (E1-06). Комбо вида на **действующей** карточке (`:220-224`) и оба пути восстановления в архиве (`archive_dialog.py:184`, `:196`) берут список из `DirectoryService.list_assignable_employment_types_for_branch(branch_id)` (E1-22); выбранный `employment_type_id` передаётся в `restore_employee_with_employment_type`. Флажок «Показывать ошибочные записи» снят по умолчанию; `_reload` с `include_erroneous`; режима «только ошибочные» нет.
