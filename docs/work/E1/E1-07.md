## Цель
Действие «В архив» показывает только три архивирующих вида; для `transferred` — выбор филиала назначения (не скрытый, не домашний); комбо вида на форме действующей карточки без архивирующих кодов; UI вызывает **новые** методы E1-06 (не удаляет старые в сервисе).
