## Цель
На `origin/master` `src/ui/directories_dialog.py` управляет только видами занятости; **отдельного раздела статусов доступности нет** (`git grep -n availability origin/master -- src/ui/directories_dialog.py` -> нет совпадений). Добавить редактирование дополнительных статусов **филиала-владельца** по образцу E1-14 (порядок `sort_order`, CRUD, скрытие); **селектор филиала-владельца** (`owner_branch_id`); базовый набор из посева `0001` не редактируется как дополнительный. Вызовы — через `AvailabilityStatusService` (E1-20). E4 подставит домашний филиал по умолчанию.
