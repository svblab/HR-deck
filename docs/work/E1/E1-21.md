## Цель
На `origin/master` `src/ui/directories_dialog.py` управляет только видами занятости (`kind="employment_type"`); **отдельного раздела статусов доступности нет** (`git grep -n availability origin/master -- src/ui/directories_dialog.py` -> нет совпадений). Добавить в том же диалоге редактирование дополнительных статусов домашнего филиала по образцу E1-14 (порядок `sort_order`, CRUD, скрытие); базовый набор статусов из посева `0001` не редактируется как дополнительный. Вызовы — через `AvailabilityStatusService` (логика E1-20).

## Не входит
Схема (E1-19); guard сервиса (E1-20); виды занятости (E1-14); назначение статуса на карточке (`status_assign_dialog.py`).
