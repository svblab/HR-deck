## Находки (§0.2)
1. Симптом: `tests/integration/test_transport_generation_migration.py` вызывает `apply_pending_migrations(conn2)` без pin и ждёт `applied == [19]`; после 0020 apply вернул бы `[19, 20]`. Причина: тест привязан к «следующая миграция = 19», а не к каталогу ≤19. Объём: карточка не включала файл — gap; закрыт GO Maintainer pin на `_migrations_through(19, tmp_path / "v19apply")`.
2. Симптом: `tests/integration/test_migrations.py::test_initial_migration_creates_schema_and_seeds` падал — dict без `transferred`/`erroneous`. Причина: ожидание устарело после посева §1.1. Объём: вне `allowed_paths`; закрыт GO Maintainer (две строки в expected dict).
3. Симптом: `tests/unit/test_reports_dialog.py::test_filter_combos_include_all_option_and_expected_counts` — `employment.count()` 7 vs 5. Причина: «Все» + 6 видов вместо 4. Объём: вне `allowed_paths`; закрыт GO Maintainer (`== 7`).
Иных правок вне объёма не делалось.
