## Цель
В `RosterRow` — поле `employment_type_code: str = ""` (значение по умолчанию — **пустая строка**, последнее поле dataclass), чтобы существующие конструкторы и хелперы `_row()` / `_roster_row()` не ломались без правки. В `RosterFilters` — флаг `include_erroneous: bool = False`, добавленный **последним** среди полей. `apply_filters`: при `include_erroneous is False` отбрасывает строки с `employment_type_code == "erroneous"`; при `True` — оставляет их вместе с остальными (режима «только ошибочные» нет). Если в `RosterService.list_rows` передано `filters=None`, `apply_filters` **не вызывается** (`src/services/roster.py:76-78`) — строки с кодом `erroneous` **не скрываются**. Исключение ошибочных из отчётов и счётчиков — вне scope (E12, ТЗ 4.7.2).

`RosterService._to_row` заполняет код по `emp.employment_type_id` через `EmploymentTypeRepository.get(employment_type_id)`; репозиторий создаётся в `RosterService.__init__`; **сигнатура конструктора не меняется** (`src/data/directories.py:419-425`).

## Не входит
UI формы «Архив» и передача флага из Qt (E1-07); видимость по умолчанию решена Johan 2026-11-04 и реализуется здесь значением `include_erroneous=False`; исключение ошибочных из отчётов и счётчиков (E12, ТЗ 4.7.2); главный экран и `roster_panel.py` (действующие карточки).
