## Цель
В `RosterRow` — поле кода вида занятости (`employment_type_code`, строка) со **значением по умолчанию** в dataclass, чтобы существующие конструкторы и хелперы `_row()` / `_roster_row()` не ломались без правки (проверить по `rg "RosterRow\("` из карточки). `RosterService._to_row` заполняет код по `emp.employment_type_id` (при необходимости — lookup через репозиторий/справочник в `src/services/roster.py`; отдельного репозитория видов в конструкторе сейчас нет). В `RosterFilters` — флаг «только ошибочные записи» (канонический код `erroneous` после E1-01); `apply_filters` отбирает строки с этим кодом при включённом флаге; при выключенном флаге поведение **как сейчас** для всех существующих вызовов (флаг по умолчанию false).

## Не входит
UI формы «Архив» и передача флага из Qt (E1-07); видимость ошибочных в списке архива по умолчанию (решение Maintainer в E1-07); исключение ошибочных из отчётов и счётчиков (E12, ТЗ 4.7.2); главный экран и `roster_panel.py` (действующие карточки).
