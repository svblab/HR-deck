## Цель
В таблице `employees` есть nullable `transfer_target_branch_id` с внешним ключом на `branches`; доменная модель и слой данных читают и пишут поле; миграция не отключает внешние ключи.

## Не входит
Правила архива, которые заполняют поле (E1-06); UI выбора филиала назначения (E1-07); сериализация `transfer_target_branch_external_id` в пакете (E1-09); проверка скрытого филиала при архиве (E1-06, ТЗ 9.9.4).

## Входные условия
1. E1-01 в статусе `done`.
2. `git show origin/master:src/data/migrations/0001_initial_schema.sql | sed -n '1,120p'` -> у `employees` нет `transfer_target_branch_id`.
3. `python3 scripts/work_status.py` -> код 0.
