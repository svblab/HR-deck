## Цель
Выгрузка и приём строк сотрудника используют `employment_type_code`, опционально `employment_type_owner`, обязательный `is_archived`, `transfer_target_branch_external_id` по §5 ADR-0010; запрещены `employment_type_id`, `transfer_target_branch_id`; старый пакет с целым id отклоняется целиком; архивная реплика с неизвестным `external_id` не идёт в подбор по ФИО (4.10.9).

## Не входит
Таблицы `employment_types` / `availability_statuses` в пакете и порядок 3.7 (частично пересекается — только поля строки сотрудника); поле заголовка домашнего филиала (E6, N4/E5); снятие локальных `id` из организационных строк (E5); версия протокола и маркер (N4/E5).

## Входные условия
1. E1-01 и E1-08 в статусе `done`.
2. `git show origin/master:src/services/directory_sync.py | sed -n '155,161p'` -> целое `employment_type_id` в выгрузке.
3. `git show origin/master:src/services/employee_sync_import.py | sed -n '675,675p'` -> отсутствие `is_archived` читается как false.
4. Lookup вида по паре владелец+code: docs/adr/ADR-0010-addendum-owner-code-identity-and-exchange.md §4 (data-layer после E1-08).
