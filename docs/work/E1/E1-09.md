## Цель
Выгрузка и приём строк сотрудника используют `employment_type_code`, опционально `employment_type_owner`, обязательный `is_archived`, `transfer_target_branch_external_id` по §5 ADR-0010; запрещены локальные id в пакете (ADR-0010 §5: «Запрещены и отклоняют пакет, даже если код рядом указан: `employment_type_id`, `transfer_target_branch_id`, `status_id`»). Сегодня `src/services/employee_sync_import.py:675` трактует отсутствие `is_archived` как false — **изменить**: без ключа `is_archived` пакет отклоняется. Сегодня `src/services/directory_sync.py:155-161` выгружает `employment_type_id` с комментарием об исключении ADR-0010 — **удалить** id из сериализации строки сотрудника. Архивная реплика с неизвестным `external_id` не идёт в подбор по ФИО (4.10.9).

## Не входит
Поле заголовка домашнего филиала (E6, N4/E5); снятие локальных `id` из организационных строк (E5); версия протокола и маркер (N4/E5). Обмен таблицами справочников значений `employment_types` / `availability_statuses` (ADR-0010 addendum §2): решено Johan 2026-11-04 — не E1; ожидаемый владелец E6 (выгрузка) и E8 (приём, 3.7, 7.19.7). Блок `status_code` / статус (§7 ADR-0010) — вне scope (E8).
