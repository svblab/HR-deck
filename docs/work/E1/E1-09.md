## Цель
Выгрузка и приём строк сотрудника используют `employment_type_code`, опционально `employment_type_owner`, обязательный `is_archived`, `transfer_target_branch_external_id` по §5 ADR-0010; запрещены `employment_type_id`, `transfer_target_branch_id`; старый пакет с целым id отклоняется целиком; архивная реплика с неизвестным `external_id` не идёт в подбор по ФИО (4.10.9).

## Не входит
Таблицы `employment_types` / `availability_statuses` в пакете и порядок 3.7 (частично пересекается — только поля строки сотрудника); поле заголовка домашнего филиала (E6, N4/E5); снятие локальных `id` из организационных строк (E5); версия протокола и маркер (N4/E5).

## Входные условия
1. E1-01 и E1-08 в статусе `done`.
2. `git show origin/master:src/services/directory_sync.py | sed -n '155,161p'` -> целое `employment_type_id` в выгрузке.
3. `git show origin/master:src/services/employee_sync_import.py | sed -n '675,675p'` -> отсутствие `is_archived` читается как false.

## Критерии приёмки
1. `pytest tests/unit/test_directory_sync_employment_fields.py tests/unit/test_employee_sync_import_type_code.py tests/integration/test_sync_rejects_integer_type_id.py -q` -> проходит; пакет с `employment_type_id` -> отказ; без `employment_type_code` -> отказ; базовый код без владельца -> принимается; неизвестный `transfer_target_branch_external_id` -> отказ всего пакета.
2. `rg -n "employment_type_id" src/services/directory_sync.py src/services/employee_sync_import.py` -> не остаётся как сериализуемое поле строки сотрудника (допустимы комментарии об удалении).
3. Тест: входящая архивная строка с новым `external_id` создаёт архивную реплику без класса LOW по ФИО (`src/services/employee_reconciliation.py:61-71` — поведение меняется).
4. `ruff check` и `mypy` по `allowed_paths` -> без ошибок.
5. `git diff --stat origin/master...HEAD` -> только `allowed_paths`, карточка, отчёт.

## Что оставить после себя
Правки sync/import/validation, тесты, отчёт с «NOT VERIFIED» и «Для следующего».

## Заметки планировщика
Размер M. Issue #155 закрывается этой нормой. Проверки владельца строк справочника значений vs домашний филиал отправителя ждут поля заголовка (E6) — в E1 исполняется только нижняя граница §11 ADR-0010. Обмен новыми кодами после E1-01.
