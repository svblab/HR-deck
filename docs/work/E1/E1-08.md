## Цель
Только схема и data-layer: `employment_types.owner_branch_id`, колонка `sort_order`, снятие столбцового `UNIQUE` на `code` без `PRAGMA foreign_keys=OFF`; два частичных уникальных индекса (docs/adr/ADR-0010-addendum-owner-code-identity-and-exchange.md §4); lookup по паре `(owner_branch_id, code)` в `src/data/directories.py`. Формат кода, резерв и UI — E1-13, E1-14.

## Не входит
`availability_statuses.owner_branch_id` (см. Вопросы Maintainer); сервис формата кода и UI (E1-13, E1-14); строки пакета (E1-09); guard-логика E1-02.
