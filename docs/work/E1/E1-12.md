## Цель
После E1-07 удалить из `EmployeeService` одноаргументные `archive_employee(self, employee_id: int)` и `restore_employee(self, employee_id: int)`; все вызовы в `src/` и `tests/` перевести на явный API E1-06.

## Не входит
Новая логика архива (E1-06); UI (E1-07); отчёты erroneous (другой эпик).

## Входные условия
1. E1-07 в статусе `done` (UI уже на новом API).
2. `rg -n "archive_employee\(|restore_employee\(" src tests --glob '*.py'` -> список файлов для правки (минимум перечисленные в `allowed_paths`).

## Критерии приёмки
1. `rg -n "def archive_employee\(self, employee_id: int\)" src` -> код выхода 1.
2. `rg -n "def restore_employee\(self, employee_id: int\)" src` -> код выхода 1.
3. `pytest -q` -> код выхода 0.
4. `ruff check src tests scripts` -> код выхода 0.
5. `git diff --stat origin/master...HEAD` -> только `allowed_paths`, карточка, отчёт; бюджет не превышен.

## Что оставить после себя
Удаление legacy-методов, правки тестов, отчёт с «NOT VERIFIED» и «Для следующего».

## Заметки планировщика
Класс S. Тихий `dismissed` через `resolve_default_archiving_type` исчезает вместе с одноаргументным архивом. UI-вызовы уже переведены в E1-07 (`employee_card_form.py`, `archive_dialog.py`).

## Для следующего
Проверить, не осталось ли вызовов одноаргументного API в `tests/e2e_mechanics/` — при необходимости отдельная находка §0.2.
