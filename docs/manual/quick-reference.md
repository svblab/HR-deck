# Шпаргалка для нового пользователя (HR)

Одностраничная памятка. Полное руководство — [`user-guide.md`](user-guide.md).

---

## Вход

1. Запустите **Журнал доступности персонала** (меню или `personnel-availability`).
2. Введите логин и пароль. При долгом простое — разблокировка паролем.

---

## Главный экран за 30 секунд

| Элемент | Зачем |
|---|---|
| **Доска / Таблица** | Два вида одного списка сотрудников |
| Поиск по ФИО | Быстрый отбор |
| Филиал → Департамент → Отдел | Каскадные фильтры |
| **Показать всех** | Сброс фильтров |
| Счётчик **Требуют уточнения** | Клик — только «проблемные» статусы |
| Клик по сотруднику | Карточка и история статусов |

---

## Частые действия (HR)

| Задача | Как |
|---|---|
| Новый сотрудник | Карточка → создать, заполнить ФИО и оргструктуру |
| Статус (отпуск, командировка…) | Popup / карточка → **Назначить статус…** |
| Импорт из Excel | **Импорт** → файл → предпросмотр → подтвердить |
| Экспорт | **Экспорт** → сохранить файл |
| Стандартный отчёт | **Отчёты** → форма → Excel или PDF |
| Отчёт по своему шаблону | **Шаблоны** → версия → **Сформировать** |

Подготовка шаблонов — [`report-templates-guide.md`](../report-templates-guide.md)
(обычно делает администратор).

## Роли — что помнить

| | HR | Наблюдатель |
|---|---|---|
| Просмотр | ✅ | ✅ |
| Редактирование, импорт, статусы | ✅ | ❌ |
| Учётки, бэкап, журнал, шаблоны | ❌ (→ админ) | ❌ |

Отключённая кнопка у Наблюдателя — **норма**, не ошибка.

---

## Когда звать администратора

- Нет учётной записи / забыли пароль.
- Нужно загрузить новый шаблон отчёта.
- «Повреждение базы данных» или приложение не открывается после обновления.
- Нужна резервная копия перед крупным импортом.

Runbook администратора — [`maintenance-runbook.md`](maintenance-runbook.md).

## Ограничение шаблонов

При генерации отчёта по пользовательскому шаблону поля маркеров сейчас
заполняются **пустыми** (нет диалога параметров). Это известное поведение,
не сбой установки — см. §8 [`report-templates-guide.md`](../report-templates-guide.md).
