# Руководство по подготовке шаблонов отчётов

Документ для авторов шаблонов **вне** кодовой базы. Технический контракт
зафиксирован в [`docs/adr/ADR-0005-report-template-marker-contract.md`](adr/ADR-0005-report-template-marker-contract.md)
(версия контракта **1.0**). Примеры файлов — в каталоге [`templates_samples/`](../templates_samples/).

> **Синхронизация каталога.** Таблица маркеров ниже **генерируется** из
> `domain/template_markers.py` (`marker_catalog_markdown()`). После изменения
> каталога в коде выполните `python scripts/generate_report_templates_guide.py`.

## 1. Каталог полей и маркеров

В Excel используйте синтаксис `{{маркер}}`. В PDF — либо **имена полей
AcroForm**, либо ключи каталога в `*.regions.json` (алиасы в manifest не
применяются).

| Канонический ключ | Русский алиас (в шаблоне) |
|---|---|
| `employee.branch` | `филиал` |
| `employee.department` | `департамент` |
| `employee.division` | `отдел` |
| `employee.employment_type` | `тип_занятости` |
| `employee.full_name` | `ФИО` |
| `employee.position` | `должность` |
| `employee.status` | `статус` |
| `employee.status_from` | `статус_с` |
| `employee.status_to` | `статус_по` |
| `report.date` | `дата` |
| `report.period_from` | `период_с` |
| `report.period_to` | `период_по` |
| `report.title` | `заголовок` |

Канонический ключ можно писать в шаблоне напрямую (например `{{employee.full_name}}`);
русский алиас (`{{ФИО}}`) разрешается и разрешается в тот же ключ при загрузке.

## 2. Excel: скалярные маркеры и повторяющиеся строки

### Скаляры

Разместите маркер в ячейке, где должно появиться значение, например:
`{{заголовок}}`, `{{дата}}`, `{{период_с}}`.

### Блок повторяющейся строки (`{{#ROW}}`)

| Синтаксис | Назначение |
|---|---|
| `{{#ROW}}` | Начало **единственного** безымянного блока на листе |
| `{{#ROW:имя}}` … `{{/ROW:имя}}` | Именованный блок (имя: латиница, цифры, `_`) |
| `{{/ROW:имя}}` | Конец именованного блока |

**Правила:**

- На одном листе допускается **не более одного** безымянного `{{#ROW}}`.
- Имена открывающего и закрывающего маркера именованного блока должны совпадать.
- Внутри блока — маркеры полей (`{{ФИО}}`, `{{должность}}` и т.д.).
- При загрузке каждый неизвестный маркер **отклоняется** с указанием имени
  (`TemplateValidationError`, список `unknown_markers`).

Образец: [`templates_samples/sample_report.xlsx`](../templates_samples/sample_report.xlsx)
— скаляры `{{заголовок}}`, `{{период_с}}`, `{{период_по}}` и блок
`{{#ROW}}` с колонками сотрудника.

## 3. PDF: AcroForm или manifest регионов

PDF без поддерживаемой привязки **отклоняется при загрузке**, не при генерации.

### Вариант A — AcroForm

Имена текстовых полей формы должны совпадать с **каноническим ключом** каталога
или русским алиасом (как в Excel). Неизвестное поле → отказ при загрузке.

### Вариант B — `*.regions.json` (рядом с PDF)

Файл `<имя_pdf>.regions.json` описывает координаты подстановки:

```json
{
  "contract_version": "1.0",
  "binding_mode": "regions",
  "regions": [
    {
      "field": "employee.full_name",
      "page": 1,
      "x_pt": 200.0,
      "y_pt": 710.0,
      "width_pt": 260.0,
      "height_pt": 14.0,
      "font_size_pt": 11.0
    }
  ]
}
```

| Поле | Описание |
|---|---|
| `contract_version` | Версия контракта ADR-0005 (сейчас `1.0`) |
| `binding_mode` | Всегда `"regions"` для этого пути |
| `regions[].field` | Канонический ключ каталога (**без** русских алиасов) |
| `regions[].page` | Номер страницы, с **1** |
| `x_pt`, `y_pt`, `width_pt`, `height_pt` | Область в **points**, начало координат — **нижний левый** угол страницы |
| `font_size_pt` | Размер шрифта overlay (по умолчанию 10) |

Образец: [`templates_samples/sample_report.pdf`](../templates_samples/sample_report.pdf)
и [`sample_report.regions.json`](../templates_samples/sample_report.regions.json).

## 4. Архив исходника и сгенерированные отчёты

При загрузке приложение сохраняет **байт-в-байт копию** вашего файла в хранилище
версий. Исходный шаблон **никогда не перезаписывается** генерацией.

Каждый сформированный отчёт — **отдельный файл** на диске; в базе фиксируется
связь «отчёт → версия шаблона», под которой он был создан. Смена или архивация
шаблона не меняет уже выданные файлы.

## 5. Работа в приложении и права

На главном экране: кнопка **«Шаблоны»** → диалог библиотеки шаблонов (загрузка,
список версий, архив/восстановление, формирование).

| Роль | Права |
|---|---|
| **Администратор** | `MANAGE_REPORT_TEMPLATES` — загрузка новых версий, архив и восстановление; также генерация |
| **Сотрудник HR**, **Наблюдатель** | `USE_ACTIVE_REPORT_TEMPLATES` — просмотр активных шаблонов и генерация отчётов |

Архивные шаблоны скрыты из активного выбора, но их версии и ранее созданные
отчёты сохраняются.

Операции upload / archive / restore / generate записываются в **журнал действий**
(виден администратору, фильтр «Шаблон»).

## 6. Проверка перед загрузкой

1. Убедитесь, что все маркеры/поля из таблицы §1.
2. Для Excel — один безымянный `{{#ROW}}` на лист или корректные именованные блоки.
3. Для PDF — либо AcroForm с известными именами, либо валидный `.regions.json`.
4. Загрузите через **Шаблоны → Загрузить**; ошибки валидации показываются сразу.

См. также `tests/integration/test_template_samples.py` — validate → generate по
файлам из `templates_samples/`.
